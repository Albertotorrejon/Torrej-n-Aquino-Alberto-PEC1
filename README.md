# Metabolomics: human cachexia

Exploratory analysis of urine metabolomics from 77 patients with and without cachexia, organised as a Bioconductor `SummarizedExperiment`.

| File | Content |
|---|---|
| `Objeto datos y metadatos binario.Rmd` | Builds the SummarizedExperiment (assay + patient metadata) and saves it as `human_cachexia_SE.Rda`. |
| `Exploración de datos.Rmd` | Exploration: distributions (boxplots) and PCA by patient group. |
| `human_cachexia.csv` | Original data. |
| `Torrejon_Aquino_Alberto_PEC1.pdf` | Final report. |

---
Coursework for the MSc in Bioinformatics and Biostatistics (Universitat Oberta de Catalunya). Reports are in Spanish.
